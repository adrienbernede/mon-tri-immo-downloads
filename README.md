# Mon tri immo

Extension pour Firefox sur ordinateur : elle aide à classer les annonces immobilières Leboncoin pendant une navigation manuelle. Les classements et les notes restent dans le stockage local du profil Firefox.

## Télécharger et installer

1. Ouvrir la [dernière version stable](https://github.com/adrienbernede/mon-tri-immo-downloads/releases/latest).
2. Télécharger le fichier `mon-tri-immo-0.1.0.xpi` dans les fichiers de la version. Seul le XPI signé par Mozilla permet une installation durable.
3. Dans Firefox, ouvrir **Modules complémentaires et thèmes**. Dans le menu de la roue dentée, choisir **Installer un module depuis un fichier…**, sélectionner le XPI et confirmer.

La version 0.1.0 est compatible avec Firefox pour ordinateur à partir de la version 140. Elle n’a pas été préparée pour Firefox sur Android ou iOS. Les mises à jour de cette distribution non répertoriée s’installent manuellement.

Ce dépôt contient uniquement les fichiers destinés au téléchargement. Le projet source reste dans un dépôt privé. Licence MIT. Cette extension est indépendante de Leboncoin.
